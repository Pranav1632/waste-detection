# Smart Waste Classifier

A deep learning project that classifies waste images into **Organic** and **Recyclable** categories using **Transfer Learning** with **MobileNetV2**.

## Features

- TensorFlow/Keras
- MobileNetV2 Pretrained Model
- Transfer Learning
- Image Classification
- Feature Extraction
- CPU Training Supported

## Dataset

Waste Classification Dataset from Kaggle.

Download it manually and place it inside:

dataset/
